# 🏠 House Price Prediction Web Application

## 📌 Project Overview

House Price Prediction is a Machine Learning based web application that predicts the estimated price of a house based on user-provided property details.

The application uses a trained Machine Learning regression model and provides users with a simple interface to enter house features and get an instant price prediction.

The system also stores prediction records in MySQL and provides prediction history and dashboard statistics.

---

## 🚀 Features

✅ User-friendly home page for house price prediction

✅ Machine Learning based price prediction

✅ Input validation for accurate results

✅ Generates downloadable PDF prediction reports

✅ Stores prediction details in MySQL database

✅ Prediction history tracking

✅ Dashboard with prediction statistics

✅ Interactive and responsive web interface
